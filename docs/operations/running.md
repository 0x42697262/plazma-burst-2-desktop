# Running

## Start modes

| Command | What it starts | Flag that can turn it off |
|---|---|---|
| `npm start` | The game window: the server list, then the official server or a private one | (none; `server_list` off goes straight to the official game) |
| `npm run sadburst` | Sad Burst 2 in its own session ([client-sadburst](../features/client-sadburst.md)) | `client_sadburst` |
| `npm run host -- [options]` | Remote play: testers play games on this machine from a browser ([remote-play](remote-play.md)) | `remote_play` |
| `npm run p2p-host` | The player-hosted dedicated host ([p2p-host](p2p-host.md)) | `p2p_host` |
| `npm run server` | Your own lobby server, no Electron ([private-server](private-server.md)) | (separate program) |
| `npm start -- --features` | Prints every feature flag, on or off and why, and quits | |

Every Electron start mode builds first (`npm run build`): the console, the server list
page, the hooks runtime and the remote-play client go to `dist/`.

## Settings

| Variable or argument | Default | What |
|---|---|---|
| `PB2_FEATURES=+id,-id` | | Turn features on or off for this start ([feature flags](../architecture/feature-flags.md)). `data/features.json` does the same, kept. |
| `PB2_DEV=0` | on | The same as `-dev_console`. |
| `PB2_HOOKS=0` | on | The same as `-hooks`. |
| `PB2_GAME_DIR` | `game/` (Sad Burst 2: `game.sadburst/`) | Play a different game copy. |
| `PB2_VERSION` | from `pb2-version.json` | The version folder used in the URL. |
| `PB2_LOGIN`, `PB2_PASSWORD`, `PB2_UID` | `data/credentials.json` | Login cookies ([login](../features/login.md)). |
| `--verbose` / `-v`, `--log-level=<level>`, `PB2_LOG_LEVEL` | `info` | Terminal log level: `error`, `warn`, `info` or `debug`. `debug` adds every request, window events, the page's `console.debug` and the game's own `trace()` output. |
| `--log-format=json`, `PB2_LOG_FORMAT=json` | text | One JSON object per log line. |

Every setting is read once, at start, by `src/kernel/config/`; a value it cannot use
stops the start with the reason, before any window opens.

## Local data

Everything the app, the private server and the tools keep on this computer is in
`data/` (not in git, except the `*.example.json` templates). Every path is defined once,
in `src/kernel/config/paths.ts`.

| Path | What |
|---|---|
| `data/credentials.json` | Your PB2 login ([login](../features/login.md)); copy `credentials.example.json` |
| `data/dev-overrides.json` (Sad Burst 2: `dev-overrides.sadburst.json`) | Console settings, binds, history and profiles |
| `data/features.json` | Feature flag overrides ([feature flags](../architecture/feature-flags.md)) |
| `data/names.js`, `data/opcodes.js` (and `.sadburst.js`) | Generated by `npm run find-names` and `npm run fetch-opcodes` |
| `data/maps/` (Sad Burst 2: `maps.sadburst/`) | Saved and local maps ([map cache](../features/map-cache.md)) |
| `data/servers.json` | The server list ([server list](../features/server-list.md)) |
| `data/remote-testers.json`, `data/remote-data/` | Remote play testers and their console settings |
| `data/p2p-host.json`, `data/server.json`, `data/p2p-host-overrides.json` | The player-hosted host's settings ([p2p host](p2p-host.md)) |
| `data/netlogs/` | Network logs ([netlog](../features/netlog.md)); they hold logins |
| `data/fingerprint/` (Sad Burst 2: `fingerprint.sadburst/`) | The main server's fingerprinter versions |
| `data/screenshots/` | Screenshots |
| `data/server/` | The private server: `server.json`, its certificate, bans and downloaded maps ([private server](private-server.md)) |

Before `data/`, these lived in `desktop/`, `server/` and folders at the repository root.
The app, the private server (with its default folder) and every tool that reads or writes
local data move what is still in an old place into `data/` when they start, once, and
say what they moved (`src/kernel/data/`, the table in `keys.ts`). Nothing is
overwritten: when both the old and the new place exist, the new one is used, the old one
stays, and every start says so until it is merged or deleted. Emptied old folders are
removed; `hooks/` (your code) and `game*/` (downloaded) stay where they are.

## Checks

- `npm run verify`: lint, type check, every test, build. Run it before every commit.
- `npm run smoke -- --run "<console line>"`: starts the real app over the DevTools
  protocol, plays the official server from the server list, and prints what each console
  line printed.
